# Giant Clock Website

A simple customizable clock made using HTML, CSS and JS

## Description

This is a Giant clock made using HTML, CSS and JS. It also has a settings option to change font and background.

This can be used as a display in background.

Supported Fonts-
* Montserrat
* Oswald
* Pixelify Sans
  
You can even set different fonts for date and time. 
It includes 2 different backgrounds to switch between.
